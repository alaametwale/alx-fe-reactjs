# Form Handling in React

This project demonstrates advanced form handling techniques in React using:

- Controlled Components
- Formik
- Yup validation

It is part of the ALX Front-End ReactJS program.

---

## Project Setup

This project was created using Vite and React.

To create the project:

```bash
npm create vite@latest form-handling-react -- --template react
cd form-handling-react
npm install
